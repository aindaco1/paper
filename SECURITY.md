# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/aindaco1/paper/security/advisories/new). Do not post private logs, exploit credentials or user information in public issues.

Describe the affected Paper version, macOS version, reproduction steps and expected impact using synthetic inputs. Reports submitted through the app create public issues, so use private reporting for security problems.

The current release receives fixes. Updates require Sparkle's Ed25519 verification and use Developer ID-signed, notarized builds. Paper does not contain GitHub credentials. Public diagnostic reports are strictly bounded and allowlisted on the client and relay; opening the preview does not send a report.
