# Paper 1.0 validation

Target: Paper 1.0.0 (10), arm64, minimum macOS 13.0. Feature work from the local 0.5.0 build is combined with the published 0.4.2 shared-desktop migration. Platform is pinned by `platform-desktop.json`; Sparkle remains 2.10.0.

## Source and app checks

- 91 Paper XCTest cases passed (62 app/renderer/adapter and 29 pure policy); seven Platform desktop tests passed.
- Exact Platform/package/Sparkle pins, vendored hashes, documentation, tracked-secret scan, four relay contracts and two native-oracle tests passed.
- The Developer ID build passed `./script/build_and_run.sh --verify` on M1 Max/macOS 27. Settings retained Soft Wove at 34%, coarse grain, Atoll exclusion and the user's power/login choices.

- Nine native workflow, 23 virtual-display and six fullscreen cases passed. Display topology was restored. Earlier attempts interrupted by foreground changes were discarded and rerun; assertions were not weakened.
- The display/fullscreen suites used Developer ID executable SHA-256 `b09fc7de384db18d0cde71959759ea52c735947602b716aafa75a4c60f82a887`. The nine workflow checks were repeated on the notarized app; its code-directory identity is retained for comparison with the final package. A later display rerun was interrupted by another foreground app and is not counted as an additional pass. No application source changed between these builds.
- The source-archive validator caught macOS AppleDouble metadata in the ZIP. Packaging now omits resource forks, extended attributes and quarantine data; the source must match the committed files and exact Platform archive with no extras.

## Distribution evidence

The [1.0 release entry](https://github.com/aindaco1/paper/releases/tag/v1.0.0) records the final publication and updater acceptance. Exact-source main-branch CI, app/DMG notarization, mounted-installer checks, a fresh source-ZIP build, public checksums and signed feed, and a real 0.4.2-to-1.0 upgrade are required by the [release workflow](../releasing.md). Local receipts, executable hashes and machine-readable evidence are retained in `outputs/`; use `script/verify_release.py --ref v1.0.0` to repeat artifact checks. These distribution checks do not substitute for the physical matrix below.

The [0.5.0 validation](0.5.0.md) records prior physical reading-strip/presentation and app-look acceptance. Older sleep/wake and HDR/input checks are historical; those physical tests are not silently re-certified by this release.

## Remaining qualification

- Actual login startup, Stage Manager and audible VoiceOver: deferred by the user.
- macOS 13–26, base-memory M1, other Apple Silicon Macs, external HDR displays and docks: no additional hardware available; use the current Mac only.
- Whole-device discharge: prepared `Tests/performance/battery.py`, deliberately deferred until an idle/unplugged session. Process energy is not a battery-life claim.
- Genuine App Store/Apple Pay and third-party recording/sharing: provider-specific qualification remains; no universal capture guarantee.
