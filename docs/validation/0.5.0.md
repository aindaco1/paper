# Paper 0.5.0 local validation

This is a local build, not a published GitHub/Sparkle release. New features reuse the pinned Deckle renderer, Record-derived Carbon shortcut pattern and existing Platform desktop/display tooling.

## Feature scope

Implemented: one-instance ownership; system-appearance switching; editable/optional shortcuts; per-texture intensity recall; low-battery threshold; menu favorites; static Desk Lamp; app-specific looks; display-matched desk profiles; reading strip; persistent presentation pause. Paused overlays are closed and discarded.

The menu contains immediate actions. Settings contains look/profile assignments, lighting/strip configuration and shortcut bindings. Snooze and presentation actions are not duplicated there. Display exclusions, manual off, snooze and presentation pause survive desk changes. App looks override day/night looks; manual texture/look selection ends automatic switching.

## Checks

- 91 XCTest cases passed: 62 app/renderer/adapter tests and 29 pure-policy tests. Includes backward migration, AppKit appearance observation, app-look precedence, profile restore/global-pause preservation, Carbon conflict handling and instance-lock ownership/symlink rejection.
- Platform pin/license/source checks, documentation validation, two native-oracle tests and four relay-contract tests passed.
- Nine native workflow cases passed: lamp/strip window configuration, no overlay windows for five pause/exclusion cases, concurrent duplicate launches from separate app copies, one winner of a cold launch race, and lock recovery after killing the owner.
- 23 virtual-display and six fullscreen checks passed. Geometry, intensity, focus, app/display exclusion, floating panels and topology restoration are covered. Evidence JSON contains exact executable hashes.
- Real bundled UI: macOS-appearance light/dark look selectors, city-free setup, effective 37% dark look, low-battery controls, saved/recalled desk, app assignment sheet, lighting and strip configuration, and disabled Save for an invalid shortcut modifier combination were inspected.
- After the user brought the controlled fixture forward, the live overlay changed to the assigned light look at 19%; the fixture accepted its click action. This is foreground/app-look evidence, not a new physical-pointer certification.
- UI automation cannot reliably focus menu-bar extras or send global shortcuts. Physical checks are recorded separately below; source/unit checks are not substituted for them.

## Physical confirmation

The user confirmed that the menu’s **Show reading strip** displays a clear horizontal band, **Pause for presentation** removes the texture/lighting, and **End presentation pause** restores it. The user also brought the app-look fixture to the foreground for the measured 19% transition.

The test-only LocalAuthentication evaluation completed while Paper was paused, and the window probe confirmed no overlay windows. The protected system UI is not exposed to this automation; this is not a claim of App Store or Apple Pay qualification. The fixture performs no purchase, account operation or action after authentication.

## Final local artifact and performance

Developer ID signing, Apple notarization, stapling and Gatekeeper acceptance passed. `Paper.app` is version 0.5.0 (9), arm64, targeting macOS 13.0. Its executable SHA-256 was `01f23b220383d122a01048aa9241a98fe732cdc70dec649ee6a012615f399d9f`; the local build manifest retains its receipt. The previous 0.4.1 app was retained for rollback during that validation. No public release/feed was changed.

A 120-second process sample with the static lamp and reading strip enabled averaged 0.012% of one CPU core and 0.00 idle wakeups/second, with peak physical footprint 28.3 MiB. Kernel-attributed energy was 6.641 mW. This short sample excludes WindowServer, GPU/display and other processes; it is not a battery-life result. Background desktop activity was not controlled.

The delivered `outputs/Paper.app` was reopened and its running executable verified against the final hash. The UI showed Soft Wove at 34%, coarse grain, Atoll exclusion, Low Power pause and existing login/shortcut preferences. Test profiles, looks and assignments were isolated and removed. Optional new features remain off in the normal preferences.
