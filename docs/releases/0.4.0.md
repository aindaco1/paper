# Paper 0.4.0

Paper adds signed updates and reviewed support reports to its local texture overlay. Update checks can run automatically; installation remains your choice. Help & diagnostics can save a filtered report or send it to this repository, where matching reports are grouped. It also accepts a Paper crash log and removes private fields before showing the preview.

All 26 textures, saved looks, Shortcuts, schedules, battery rules, display/app exclusions and library backups remain available. Your existing appearance and rules are preserved. Versions through 0.3.0 require this first update to be installed manually.

Targets Apple Silicon and macOS 13+. Hardware/OS acceptance is documented separately; development and physical testing have focused on an M1 Max running macOS 27. Review the privacy and support documentation before sending a public report.
