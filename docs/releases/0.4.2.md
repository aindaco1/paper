# Paper 0.4.2

Paper now pins version 0.2.0 of Platform's shared desktop package. The same
Sparkle controller and reviewed-report transport serve the other Dust Wave
macOS apps, with product-specific settings and diagnostic policy kept in Paper.

Automatic checks, user-approved update installation, report review and retry
behavior retain their existing rules. Texture rendering and saved settings are
unchanged. See the [migration record](../SHARED_DESKTOP_MIGRATION.md).
