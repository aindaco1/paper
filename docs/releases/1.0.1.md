# Paper 1.0.1

Fixes Paper covering or blacking out the Space previews at the top of Mission Control (F3). The texture now hides during the overview and returns promptly when you leave, including repeated entry and exit. Manual off, display exclusions and other pause rules still take priority.

This maintenance release also adopts Dust Wave Platform's shared Apple support core. Report review, explicit submission and update consent retain their existing behavior.

Install with **Check for Updates…**, or open the DMG and drag Paper to Applications. Existing settings and imported papers are preserved.

See [the migration record](https://github.com/aindaco1/paper/blob/v1.0.1/docs/SHARED_SUPPORT_MIGRATION.md) for dependency and rollback details. The app targets macOS 13+ on Apple Silicon; this fix was exercised on an M1 Max running macOS 27. Broader hardware and OS qualification remains listed in the [roadmap](https://github.com/aindaco1/paper/blob/v1.0.1/docs/roadmap.md).
