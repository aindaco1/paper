# Paper 0.4.1

Settings is simpler: the main on/off toggle handles comparison, and Snooze stays in the menu bar.

Help & diagnostics now places Refresh, Import crash log, Save report and Send in a single aligned footer. The privacy description and status messages wrap so their full text stays readable.

This update retains the signed updater and reviewed GitHub reporting introduced in 0.4.0. Matching reports aggregate in one issue; reports are sent only after you review them and choose Send. Existing appearance, rules and library are preserved.

Targets Apple Silicon and macOS 13+. Physical acceptance has focused on the built-in XDR display of an M1 Max running macOS 27; other hardware and older macOS versions remain to be qualified.
