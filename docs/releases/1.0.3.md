# Paper 1.0.3

Fixes the texture disappearing when you reveal the Dock or use Command-Tab. Paper now distinguishes those system surfaces from Mission Control, which still hides the texture during the overview and restores it afterward.

Regression coverage includes both real desktop interactions, repeated Mission Control entry/exit, fullscreen, display exclusions and floating panels. Existing settings and libraries are preserved.

Apple Silicon, macOS 13 or later. Local acceptance uses the current macOS 27 host; the remaining hardware and OS qualification limits are in the [roadmap](../roadmap.md).
