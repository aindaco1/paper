# Paper 1.0

Paper is a free, open-source texture overlay for Apple Silicon Macs, with 26 Deckle papers and Soft Wove as the default. This release brings the new reading and workspace features together with Platform desktop 0.2.0, used by the existing signed updater and reviewed diagnostic reporting.

- Apply saved looks automatically for an app, macOS appearance or sunrise/sunset.
- Recall a desk profile when its display setup reconnects; remember intensity per texture.
- Use a clear reading strip and optional static warm Desk Lamp.
- Pause for presentations, choose favorites and snooze from the menu. Settings holds configuration, assignments and shortcut bindings.
- Customize global shortcuts, pause at a chosen battery percentage, and safely reopen one running instance across app copies.

Manual off and display exclusions always win. Presentation pause persists until ended; paused overlays are removed. Existing settings, recipes and saved looks are preserved, and optional new effects start off.

Open the DMG and drag Paper to Applications, or use **Check for Updates…** in an updater-enabled version. Quit a pre-1.0 copy before installing manually. Versions through 0.3.0 need a manual install.

The app targets macOS 13+ and arm64. Testing used an M1 Max on macOS 27; other OS/hardware combinations, login startup, Stage Manager, audible VoiceOver and whole-device battery discharge remain documented qualification work. Pause before sharing, capturing or using protected authorization UI; Paper does not promise capture invisibility. See the [validation record](https://github.com/aindaco1/paper/blob/main/docs/validation/1.0.0.md).
