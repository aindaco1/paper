# Roadmap

Implemented: all 26 Deckle textures, Soft Wove default, favorites/looks, Shortcuts, schedules and solar looks, battery rules, display/app rules, Atoll panel handling, imports and library backup. Version 0.3.0 passed native fullscreen and one physical sleep/wake cycle on M1 Max/macOS 27.

Current 0.4.0 work: shared signed updating, reviewed diagnostic/crash delivery and aggregation, public release infrastructure, and integration/HDR acceptance. Final evidence lives alongside the delivery in `outputs/`; source checks alone do not establish these runtime passes.

Remaining wider qualification: macOS 13–26, other Apple Silicon machines including base-memory M1, physical external/HDR displays and docks, and whole-device battery discharge. An online gallery, editor and Windows port remain outside the small macOS scope.
